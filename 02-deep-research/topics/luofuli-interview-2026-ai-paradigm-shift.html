AI范式巨变：从Pre-train到Post-train的代际转折
——罗福莉深度访谈全解读

📅 访谈时间：2026年3月 📝 报告日期：2026-04-25 🎙 来源：张小珺《商业访谈录》第138期 ⏱ 访谈时长：3.5小时
2026年，Anthropic Claude Opus 4.6与开源框架的联合冲击，引发了AI行业的范式巨变。本报告基于罗福莉（小米MiMo团队负责人、前DeepSeek核心成员）的首次深度访谈原文（约2万字），结合36氪、Binance等多源信息交叉验证，全面解读这场"悄无声息的伏击"所揭示的深层规律：竞争重心从"谁的预训练数据更多"转向"谁的后训练基础设施更敏捷"。

小米大模型团队负责人 · 前DeepSeek核心成员 · 前阿里达摩院
MiMo-V2主导研发 DeepSeek V3参与者 R1项目亲历者 RL Scaling研究者
📌 为什么研究这个？

2026年3月，小米MiMo团队匿名将 MiMo-V2-Pro（代号Hunter Alpha） 上传至全球最大API聚合平台 OpenRouter，在外界不知道是哪家公司的情况下，连续多天登顶日榜调用量，总调用量突破1万亿tokens。OpenClaw创始人Peter Steinberger亲自在X上打听这是谁家的模型。

与此同时，Anthropic的Claude Opus 4.6彻底重塑了行业认知：从"对话机器人"到"自主完成复杂任务的Agent"，一场以"伏击"方式推进的范式转变，在整个2026年Q1悄然完成。

罗福莉作为亲身经历了从DeepSeek到小米、从R1到MiMo-V2全过程的顶级研究者，她的视角是理解这场范式转变最直接的一手窗口。这是她的首次公开深度访谈。

核心发现 01 · 已交叉验证
🎯 范式转战：算力重心从"预训练"转向"后训练"，代差窗口只剩2-3个月
支撑数据：Chat时代算力分配为 研究:Pre-train:Post-train = 3:5:1，现合理比例已变为 3:1:1，顶尖团队更是 1:1。这意味着后训练算力规模与预训练等量级，是近十年来最大的资源配置变革。
为什么重要：预训练代差基本消除，国内团队在Pre-train结构上甚至有优势（MLA → Hybrid+MTP）。Agent Post-train成为新战场，而国内接近Claude水平的时间窗口只有2-3个月。
"接下来两三个月，大家怎么发生变化，是考验团队整体研究水平、技术敏捷程度，以及怎么拥抱新的范式来做研究的关键。" — 罗福莉，访谈原文（2026年3月）
→ 行动建议：立即评估团队Post-train算力投入比例，是否需要调整到接近1:1
核心发现 02 · 已交叉验证
🚀 "悄无声息的伏击"：MiMo-V2-Pro匿名登顶OpenRouter，宣告中国追赶速度超出预期
支撑数据：Hunter Alpha（MiMo-V2-Pro匿名版）在OpenRouter无需揭晓身份的情况下，连续多天调用量登顶日榜，匿名期总调用量破1万亿tokens；被误认为DeepSeek V4，甚至连OpenClaw创始人也来打听。
为什么重要：这是"同一起跑线"的第一个有力证明——不靠品牌、不靠背书，只靠模型实力就能获得全球开发者认可。国内团队进入"快速追赶阶段"不再只是判断，而是已经用事实验证。
"正如我一个月前说的，我们追赶Claude Opus 4.6很快。" — 罗福莉，MiMo-V2.5-Pro开测时评价（2026年4月）
→ 行动建议：不应再用"追赶"心态，而应以"同一起跑线竞争"姿态全力投入Agent Post-train
核心发现 03
🧩 开源框架是新一代"群体智慧加速器"：框架×模型协同进化，超越单一顶尖模型
支撑案例：小米近百人团队在飞书群组中同时改进开源框架，数小时迭代一轮，中层模型（MiMo接入）在复杂Agent任务上逼近顶尖模型。"一套很复杂的Agent框架设计，能弥补非常多模型能力的短板。"
为什么重要：开源框架使"激发中层模型上限"成为可能。未来核心竞争力不是"有没有最强模型"，而是"有没有最好的框架×模型协同能力"。
"大家的想象力是一个乘积作用……从被这个框架点燃热情，到它产生价值的过程，我从群体智能收获的成长更大。" — 罗福莉
→ 行动建议：主动参与开源框架生态（贡献Skills、Agent架构），比单纯训练更大模型的ROI更高
核心发现 04
🏗 组织"平权"不是哲学，是RL Infra工程学的必然选择
支撑案例：没有组、没有职级、没有deadline的团队，训出1T参数基座模型；让预训练人做后训练，带来数据多样性视野优势。RL Infra天然要求"容忍模糊性"——不能追求Pre-train式的精确控制。
为什么重要：传统"分层精确管理"模式在Post-train时代是效率的对立面。RL实验本质是"模糊探索"，需要高度容错、快速迭代，与层级制度内在冲突。
"任何层级，一定程度都是规范和约束，而规范和约束本身是压制创造力的。" — 罗福莉
→ 行动建议：为AI研究团队设计"双轨制"——Pre-train（确定性高精度）vs Post-train（模糊容错快迭代）
核心发现 05
⚡ "左脚踩右脚"临界点：AI训练AI的递归跃迁，2年内到来
支撑判断：罗福莉预测AGI进度当前为20%，今年能到60-70%，两年内可能实现。"AI自己左脚踩右脚就提升了"——连研究员自身的创造性工作也开始被AI替代。这是对工作岗位最深刻的存在性挑战。
反面观点：此判断基于单一访谈者乐观预测，需注意预测误差。历史上多次"AGI两年内到来"的预测均未实现。但"研究者工作被AI替代的速度超预期"这一具体现象有更多实证支撑。
→ 行动建议：研究者的不可替代价值在于：提供"另类信息"（Skills中的内部知识）、构建评估体系、做架构判断

🔍 技术维度：为什么MTP+Hybrid Attention天然适合Agent时代

⚙️ MiMo-V2模型结构决策解析

罗福莉团队在大多数同期竞争者选择MLA（Multi-head Latent Attention）时，选择了Hybrid Attention（混合注意力）+ MTP（Multi-Token Prediction）架构，事后证明这是为Agent时代天然准备的。

维度 MLA（DeepSeek/GLM/Kimi路线） Hybrid+MTP（MiMo路线）
设计目标 Chat时代：最优访存/计算比，H系列芯片极致优化 Long Context + Agent：效率+灵活性
KV Cache 极小（核心优势），但已达compute/memory bound 通过Sliding Window更省，可做多级缓存
推理速度 受compute bound限制，难加MTP加速 Flash/Pro均达80-150 TPS，用户感受"快"
可扩展性 结构固定，Post-train发挥空间受限 Simple结构留有富余算力，MTP充分利用
Post-train适配性 需提前确定推理场景，灵活性差 可适配1M+ Context，RL Infra灵活扩展
"你要是能把它推理效率做好了，后面在Agent时代，也有一个更有价值的事情……大模型可以塞更多的上下文，它就又更强。" — 罗福莉

⚡ 算力维度：卡的配置比例正在发生历史性重写

📊 GPU配置比例演变（已多源验证）
时期研究:Pre-train:Post-train驱动因素
Chat时代（2023-2025） 3 : 5 : 1 预训练是核心战场，对话需求简单
当前合理比例（2026Q1） 3 : 1 : 1 Agent范式兴起，Post-train开始等比例投入
顶尖团队现状 ~= 1 : 1 （Pre:Post） RL Infra成为核心竞争力，算力全面转移

这一变化意味着：单纯拥有大规模算力不再是护城河，关键在于能否建立"高效RL Infra + 快速实验循环"的能力体系。一个月出一个Post-train模型已经成为可能，而预训练时代这个周期至少是一年。

🔮 短期趋势（2026年Q2-Q3）

短期趋势 · 2-3个月内
⚡ RL Infra体系建设速度决定胜负
当前阶段最关键的不是谁有更多数据或更多算力，而是：谁能最快建立"以Agent为核心"的RL Infra系统。这个系统要求容忍模糊性、支持异构资源调度（GPU+CPU+存储）、兼容不断变化的Agent框架。接下来两三个月的RL Infra建设速度，将直接决定半年后的领先格局。
短期趋势 · 2026年
🌊 推理需求"几倍到10倍"爆发，推理芯片迎来空前需求
随着Agent框架越强、模型成本越低，普通开发者和企业会以指数级方式使用AI推理服务。MiMo-V2-Pro的价格仅为Claude Opus 4.6的1/5，这一量级的价差会直接触发推理需求爆发。对推理芯片的需求将"立即发生"，怎么在现有产能下做更低成本的推理是核心命题。

💭 本质洞察

本质洞察
🧠 表象→本质：这不是"中国追赶美国"，而是"工程化能力"取代"资源规模"成为新护城河
表象：MiMo匿名登顶OpenRouter，国内团队2-3个月内追上Claude Opus 4.6。

本质规律：当预训练"资源游戏"结束，胜负转移到后训练的"工程游戏"——哪家团队能快速建立RL Infra体系、快速迭代实验循环、快速在多样化Agent框架中验证效果，谁就能胜出。这是一个从"资本密集型"到"研究效率型"的竞争范式转变。

类比：就像制造业从"谁有更多工厂"到"谁的供应链反应更快"的转变。苹果不一定有最多工厂，但它的供应链是全球最敏捷的。

趋势推演：接下来18个月，"RL Infra敏捷性"将成为大模型公司的最核心壁垒。那些还在扩大预训练规模而不投入Post-train工程化的团队，将在2-3个月内被快速甩开。
